    Correction

    Correction

    Cleans fillers, repetitions and self-corrections from the transcript.

    Self-correction

    Applies spoken corrections and revisions so your final dictation reflects what you meant. Turn off to insert the raw speech-to-text transcript with no correction diff.

    Formatting Alpha

    Apply punctuation and structure to raw transcripts. Handled by the correction provider.

    Formatting mode

    How the formatter shapes your text. Prose for polished writing, Message for casual chat, Code to preserve symbols and casing, Raw to skip formatting (cleanup only).

    Shortcuts

    Global keyboard shortcuts for dictation and hands-free modes.

    Toggle dictation

    Press once to start, again to stop. Needs at least one modifier (⌥/⌃/⌘/⇧).

    Push to talk

    Hold a key to dictate while it's pressed. Needs Input Monitoring.

    Paste last transcript

    Global shortcut to re-insert your most recent transcription into the active app. Needs at least one modifier (⌥/⌃/⌘/⇧).

    Revert to raw

    Global shortcut to re-insert the RAW (uncorrected) transcript when a correction over-edited. Needs at least one modifier (⌥/⌃/⌘/⇧).

    Command mode hotkey

    Start/stop voice command mode (edits + system commands). Needs at least one modifier (⌥/⌃/⌘/⇧).

    Allow system commands

    Let commands open apps, change volume, and run macOS Shortcuts.

    Wake word Beta

    Always-listening, on-device. The mic (and the macOS orange indicator) stay on while enabled.

    API Keys

    Vendor credentials for speech-to-text and correction. Keys are stored locally on this device.

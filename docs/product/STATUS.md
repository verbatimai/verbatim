Vanilla-TS ported from `apps/web`; the pipeline + key stay in the M2 backend (WS on `127.0.0.1:8787`), and the one widget-specific seam is `formatted` → Rust `inject_text`. Run with **`npm run widget`** (backend + `tauri dev`). Frontend typechecks clean. **Phase 3.4 ✅ DONE (14 Aug 2026) — reliable AX focus read + routing.** Root cause of the earlier `-25212`: the *system-wide* focused-element attribute is unreliable (worse for Chromium/Electron, whose AX tree is lazy). Fix (`axinject.rs read_focus`): frontmost pid via **NSWorkspace** (minimal objc FFI) → **`AXUIElementCreateApplication(pid)`** → set **`AXManualAccessibility=true`** → **poll `AXFocusedUIElement`** for the lazy tree → system-wide fallback → paste fallback (AX never blocks paste). Routing: not-trusted→copy, **secure field→refuse+copy**, editable→paste, non-editable→copy, unreadable→paste. **AX-write (`kAXSelectedText`) intentionally unused** (silent no-op on tested apps). Added a **`⌥⇧V` paste-test hotkey** (inject a fixed sentence with no backend). **This satisfies the M3 exit requirement (password fields refused).** **Phase 3.3 ~80%:** overlay joins all Spaces + full-screen (collection behaviour); caret-anchored positioning left (but the draggable-orb / remembered-position model is the current, intentional placement). **Phase 3.2 ~80% (hotkey + Wispr-style UX):** ⌥Space drives dictation with **tap-to-toggle** and **hold-to-talk** (Rust `Pressed`/`Released` state machine → `dictation` events the webview acts on).
